## GitHub Pages

這是免建置工具的靜態網站，首頁位於 `index.html`。要發布到 GitHub Pages：

1. 開啟儲存庫的 **Settings → Pages**。
2. 在 **Build and deployment** 選擇 **Deploy from a branch**。
3. 選擇 `main` 分支與 `/ (root)` 資料夾，按 **Save**。

請先編輯 `index.html` 底部的 `profile` 設定，更新姓名、介紹、電子郵件與社群連結；發布後可在同一個 Pages 設定頁查看網站網址。首頁使用的字型與封面照片由外部服務載入。
